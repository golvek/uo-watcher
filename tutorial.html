How to Use the Timer

PT-BR

The timer helps you track time spent reviewing tasks. It starts counting down as soon as a task appears on screen.

The Widget

Here is what each number means (example: you just finished your first task):

Total3m
Tasks1
Bank31s
TIMER211

What Each Color Tells You

  • Total — How long you have worked today. Goes up each time you click Submit.
    Seconds appear in the extension popup.
  • Tasks — How many tasks you have completed so far.
  • Bank — Extra seconds you saved from finishing tasks early. The timer uses these first when it hits zero.

How It Works (Step by Step)

  1. A task appears on screen → the timer starts counting down.
  2. You review the task. When the timer hits zero, it starts using your time bank.
  3. When the time bank runs out, the timer turns red.
  4. You click Submit → leftover seconds go to your bank, tasks counter goes up, total work time updates.
  5. The next task appears → timer resets and starts again.
